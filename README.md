# ⚽ Premier League Analytics Dashboard (2020/21 - 2024/25)

An advanced interactive Power BI dashboard providing deep statistical insights into the English Premier League (EPL) spanning from the 2020/21 to 2024/25 seasons.

---

## 📊 Project Overview
This project analyzes match outcomes, tactical formations, team performances, and advanced metrics like Expected Goals (xG) to uncover patterns and trends in modern English football.

---

## 🚀 Key Features & Pages
1. **Overview:** High-level summary of matches, total goals, average goals per match, and overall league trends.
2. **Team Performance Profile:** Deep dive into individual team win rates, goal differentials, home vs. away performance, and season-by-season progression.
3. **Attacking Analysis:** Evaluation of scoring patterns, top formations used by attacking teams, shot accuracy, and xG efficiency.
4. **Defensive Analysis:** Assessment of goals conceded, clean sheets, defensive formations, and defensive vulnerabilities.

## 🛠️ Tools & Technologies
* **Data Modeling & Visualization:** Microsoft Power BI
* **Data Transformation:** Power Query (DAX measures, calculated columns)
* **Design UI/UX:** Custom dark-themed layout tailored for sports analytics.

---

## 💡 Key Insights
* **Tactical Trends:** The `4-2-3-1` and `4-3-3` formations dominate modern EPL usage and yield the highest goal conversion rates.
* **xG vs Actual Goals:** Noticeable alignment between expected goals and finishing efficiency in top-6 contenders across recent seasons.
